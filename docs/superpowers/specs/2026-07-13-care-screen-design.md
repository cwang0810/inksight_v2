# 商用落地案例收敛 · 第一案例：长辈关怀屏 — 设计文档

日期：2026-07-13
状态：设计已确认，待实现规划

## 背景与决策

InkSight 当前有 28 个内置模式，是"能力演示集"而非"场景产品"。目标是收敛为几个**端到端完整、拿得出手的演示案例**（面向潜在客户/合作方/投资人），暂不追求销售规模。

已确认的决策：

1. **商业形态暂不锁定**。典型案例是 ToC 销售、ToB 试点、Developer Kit 参考实现的共同前置工作。
2. **成功标准**：完整可演示的端到端案例，演示中不允许出现"假设一下""手动改配置"类断点。
3. **案例驱动，机制后提炼**：不先建通用"场景包"基建。第一个案例专属实现，第二个案例落地时再提炼共性机制，基建永远滞后于案例。
4. **案例顺序**：长辈关怀屏 → 小店今日推荐牌 → 个人晨间简报台 → 学习卡片（可选）。
   - 关怀屏：自闭环（无外部集成依赖）、情感故事最强，第一个做。
   - 推荐牌：与关怀屏共性明显（外部人经网页向设备投内容），第二个做并提炼机制。
   - 简报台：依赖 ICS/CalDAV 日历集成，鉴权琐碎，往后放。
   - 学习卡片：需固件迭代且受众窄，最后做或砍掉。
5. 现有 28 个模式**不删除、不重构**，未来退居为场景的内部积木。

## 关怀屏案例概述

**一句话**：家人扫码打开网页发留言/照片，老人桌上的墨水屏 10 分钟内显示，老人按一下按键，家人手机上看到"已查看"。

关键产品决策：

- **发送端**：免登录链接 + 设备绑定码（屏幕显示二维码），链接可转发给多位家人，微信浏览器内可直接使用。
- **消息时效**：关怀屏场景默认刷新间隔 10 分钟；发送页显示"预计 10 分钟内送达"；老人短按设备按键可立即拉取。
- **V1 功能全集**：家人文字留言、照片发送、默认关怀面板（无消息时）、按键"已看到"回执。

## 设计

### 1. 绑定与发送端（webapp）

- 设备进入关怀屏场景的方式：在现有 config.html 中将设备配置为单模式 CARE（V1 不做新的激活入口）。
- 设备首次以 CARE 模式请求渲染且尚无绑定关系时，后端自动生成绑定码，并将**二维码 + 绑定码**直接画进墨水屏渲染图；绑定完成后不再显示。
- 家人扫码进入 webapp 手机页（Next.js 新路由 `/care/[code]`），免登录；首次使用输入称呼（如"女儿"）。
- 页面功能：
  - 发送文字留言
  - 上传照片
  - 查看历史消息及"已查看"状态
  - 配置常驻提醒（如用药提醒），显示在默认关怀面板上
  - 显示设备最后在线时间（复用现有 heartbeat 数据）
- 发送成功后显示预计送达时间。

### 2. 后端（FastAPI）

- 新增 `core/care_store.py`：
  - 消息表：设备 MAC、类型（text/photo）、内容/照片路径、发送人称呼、创建时间、已读时间
  - 绑定码表：绑定码 ↔ 设备 MAC 映射
  - 数据存在现有 `inksight.db`
- 新增 **CARE 模式**：
  - 有未读留言 → 大字号渲染留言（发送人 + 时间 + 正文）；照片消息经抖动算法转 1-bit 显示
  - 无留言 → 默认关怀面板：大字时间日期 + 天气 + 家人配置的提醒 + 一句问候
  - `cacheable: false`，绕过 ContentCache（每台设备内容不同，必须实时）
- 新增家人页 API：发消息、传照片（服务端压缩、缩放、转灰度）、拉取历史、配置提醒、按绑定码校验。

### 3. 固件（改动最小化）

- 关怀屏场景仅是设备配置：单模式 CARE + 刷新间隔 10 分钟，不引入新固件概念。
- "已看到"回执复用现有 `postVocabEvent`（`network.cpp`）的实现模式：设备通过已有的 `X-Mode-Id` 响应头得知当前显示的是 CARE 留言，此状态下短按先上报 `care/seen` 事件，再照常立即刷新。
- 短按立即刷新为现有能力，兼作老人主动"收信"。

### 4. 错误处理

- 照片过大/格式不支持 → 服务端统一缩放转换，超限返回明确提示。
- 留言超长 → 发送页前置校验 + 服务端截断保护。
- 设备离线 → 发送页展示最后在线时间，管理预期。

### 5. 测试

- `backend/tests/` 新增：care_store 单元测试、CARE 模式渲染测试（有消息/无消息/照片三种状态）、绑定码校验测试。
- 端到端验收以演示故事线为准（见下）。

## 演示故事线（验收标准）

1. 全新设备激活 → 屏幕出现二维码
2. 手机扫码 → 发留言"记得吃降压药" → 页面显示"预计 10 分钟内送达"
3. 按一下设备按键 → 屏幕立刻显示大字留言
4. 再按一下 → 手机页面出现"已于 14:32 查看"
5. 传一张全家福 → 屏幕显示抖动黑白照片
6. 无新消息时 → 屏幕回到时间/天气/用药提醒面板

任何一步不能脱稿完成，即案例未完成。

## 明确不做（V1）

- 通用场景包机制（第二个案例时提炼）
- 账号体系、多设备管理
- 语音留言、双向对话
- 手机 App / 小程序（纯 H5 页面）
- 老人端除单按键外的任何交互
